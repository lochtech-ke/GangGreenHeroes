# Badge System FAQ

## Frequently Asked Questions About the New Geometric Badge System

### General Questions

#### What changed with the badge system?

We've upgraded all badges to a beautiful new geometric, low-poly art style. The new designs are:
- More visually striking
- Optimized for social media sharing
- Better performing on mobile devices
- Inspired by nature and African art

All functionality remains the same - only the visual design has changed.

#### When did this change happen?

The geometric badge system was rolled out on [Date]. All existing badges were automatically upgraded to the new design.

#### Do I need to do anything?

No! The upgrade happened automatically. All your badges, achievements, and progress have been preserved. Just enjoy the new look!

#### Can I see my old badges?

The old badge designs have been replaced with the new geometric designs. However, all your achievement data, dates, and metadata remain unchanged.

#### Why did you change the badge design?

We changed the design to:
1. Create more visually appealing badges
2. Improve social media sharing
3. Optimize mobile performance
4. Establish a unique visual identity
5. Better represent environmental achievements

### Badge Appearance

Each badge features:

- Tree Planter: Geometric tree

### Technical Questions

#### Are my badges still NFTs?

Yes! All badges remain as NFTs on the blockchain. Only the visual representation has changed - the underlying token is the same.

#### Will this affect my wallet?

No. Your badges are still in your wallet with the same token IDs. The new design is just a visual update to the metadata.

#### Do I need to re-mint my badges?

No. All badges have been automatically updated. No re-minting is required.

#### What about gas fees?

Since this is a metadata update only, there are no gas fees for existing badge holders.

#### Are the new badges on-chain?

Yes. The badge metadata, including the new SVG designs, is stored on-chain or via IPFS, depending on the badge type.

### Performance Questions

#### Will badges load slower now?

No! The new geometric badges are actually optimized for faster loading:
- Smaller file sizes (1-5KB)
- Efficient SVG format
- Lazy loading support
- Aggressive caching

#### Do geometric badges work on mobile?

Yes! The new badges are specifically optimized for mobile devices:
- Fast rendering (< 100ms)
- Smooth scrolling
- Touch-friendly interface
- Responsive design

#### Why do some badges take time to load?

Badges use lazy loading to improve performance. They load as you scroll to them. This is normal and ensures fast page load times.

#### Can I view badges offline?

Once loaded, badges are cached in your browser and can be viewed offline until the cache expires.

### Achievement Questions

#### Did my achievement count change?

No. All your achievements, counts, and progress remain exactly the same. Only the visual design changed.

#### Are the tier requirements different?

No. Tier requirements remain unchanged:

#### Can I still earn new badges?

Yes! You can continue earning badges exactly as before. All new badges will use the geometric design.

#### What about badges I'm working toward?

Your progress toward next tiers is preserved. Continue your environmental actions as normal.

### Sharing Questions

#### Can I still share badges on social media?

Yes! In fact, the new geometric designs are optimized for social media sharing and look great on all platforms.

#### What formats can I download badges in?

You can download badges in two formats:
- **SVG**: Vector format, scales to any size
- **PNG**: High-resolution image (1024x1024)

#### Will shared badges show the new design?

Yes. All shared badges, whether new or old, will display the new geometric design.

#### Can I print my badges?

Yes! Download the SVG format for the best print quality. The vector format ensures crisp printing at any size.

### Troubleshooting

#### My badges aren't showing up

Try these steps:
1. Refresh the page (Ctrl+R or Cmd+R)
2. Clear your browser cache
3. Check your internet connection
4. Try a different browser
5. Contact support if issue persists

#### Badges look pixelated or blurry

This shouldn't happen with the new SVG format. If it does:
1. Ensure you're viewing the latest version
2. Clear your browser cache
3. Check your browser zoom level (should be 100%)
4. Try a different browser

#### Badge colors look wrong

Ensure your browser supports modern CSS and SVG. Update your browser to the latest version if needed.

#### Download isn't working

Check that:
1. Pop-ups aren't blocked
2. You have sufficient storage space
3. Your browser allows downloads
4. You're logged in to your account

#### Sharing to social media fails

Verify that:
1. You're logged into the social platform
2. Pop-ups aren't blocked
3. You have permission to post
4. The platform isn't experiencing issues

### Migration Questions

#### What is badge migration?

Badge migration is the process of converting existing badges from the classic design to the new geometric design. This happened automatically for all users.

#### When was my account migrated?

All accounts were migrated on [Date]. You can check your badge details to see the migration date.

#### Can I opt out of migration?

No. The geometric design is now the standard for all badges. The classic design is no longer supported.

#### What if migration failed for my badges?

Migration failures are rare. If you notice any issues with your badges:
1. Check the badge details page
2. Contact support with your badge ID
3. We'll investigate and fix any issues

#### Will there be more migrations?

We may update badge designs in the future, but any changes will be communicated in advance and handled automatically.

### Privacy and Security

#### Is my badge data secure?

Yes. Badge data security remains unchanged:
- Encrypted storage
- Secure blockchain records
- Private by default
- You control visibility

#### Who can see my badges?

You control badge visibility:
- **Public**: Everyone
- **Friends**: Your connections only
- **Private**: Only you

#### Can someone steal my badge design?

Badge designs are public (they're meant to be shared!), but the actual NFT badge is securely tied to your wallet and cannot be stolen.

#### What data is stored with badges?

Badge metadata includes:
- Achievement type
- Tier level
- Earned date
- Forest location (if applicable)
- User ID (encrypted)
- Visual design data
