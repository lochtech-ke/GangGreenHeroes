# GG Coin System

**Your Guide to Earning, Spending, and Managing GG Coins**

The GG Coin system is the unified reward currency on the #GangGreen platform. Every action you take to help the environment earns you GG Coins, which you can use to unlock badges, features, and more.

---

## What are GG Coins?

GG Coins are the platform's unified digital currency that rewards you for environmental actions. They use decimal precision (up to 3 decimal places) to support micro-rewards and flexible pricing.

### Key Features
- **Unified System**: One currency for all rewards and transactions
- **Decimal Precision**: Support for fractional amounts (e.g., 10.500 GG Coins)
- **Real-time Updates**: Your balance updates instantly when you earn or spend
- **Transparent History**: Complete transaction log with timestamps
- **Multipliers**: Earn bonus coins for verified actions, streaks, and achievements

## Managing Your GG Coins

### Viewing Your Balance

Your GG Coin balance is displayed:
- **Dashboard**: Top of your personal dashboard
- **Navigation**: User menu (top right)
- **Profile**: Your profile page
- **Wallet Page**: Dedicated GG Coins page

### Balance Display Format

GG Coins are displayed intelligently:
- **Whole numbers**: 50 (not 50.000)
- **With decimals**: 10.500 (when non-zero)
- **Large amounts**: 1,234.567 (with thousand separators)

### Transaction History

View your complete transaction history:
1. Go to **Dashboard** → **GG Coins**
2. Click **"Transaction History"**
3. See all your earnings and spending

Each transaction shows:
- **Amount**: +/- coins earned or spent
- **Description**: What the transaction was for
- **Timestamp**: When it occurred
- **Balance**: Your balance after the transaction

### Filtering Transactions

Filter your history by:
- **Type**: Earn, spend, bonus, referral
- **Date Range**: Last week, month, year, or custom
- **Source**: Tree planting, missions, learning, etc.

## Technical Details

### Decimal Precision

GG Coins support up to 3 decimal places:
- **Minimum**: 0.001 GG Coins
- **Maximum**: 9,999,999.999 GG Coins
- **Rounding**: All calculations rounded to 3 decimals

### Caching & Performance

For fast performance:
- **Balance Cache**: 30-second cache for quick access
- **Invalidation**: Cache clears when you earn or spend
- **Query Speed**: < 50ms for cached balance
- **Transaction Speed**: < 200ms to record

### Security

Your GG Coins are protected:
- **Atomic Transactions**: All-or-nothing operations
- **Negative Balance Prevention**: Can't spend more than you have
- **Audit Trail**: Complete transaction history
- **Row-Level Security**: Only you can view your balance

## Frequently Asked Questions

### Can I lose GG Coins?
No, GG Coins don't expire or decay. Once earned, they're yours forever.

### Can I transfer coins to friends?
Not yet, but user-to-user transfers are coming soon!

### Can I buy GG Coins with money?
No, GG Coins can only be earned through environmental actions. This ensures the platform rewards real impact.

### What happens if a transaction fails?
Transactions are atomic - if something fails, your balance remains unchanged. You'll see an error message and can try again.

### How accurate is my balance?
Your balance is cached for 30 seconds for performance. After earning or spending, the cache updates immediately. The balance is always accurate within 30 seconds.

### Can I see someone else's balance?
No, balances are private. You can only see your own balance and transaction history.

### What if I find a bug?
Report it to support@ganggreen.org. If it's a valid bug affecting your balance, we'll investigate and correct it.

## API for Developers

### Get Balance
```typescript
const balance = await ggCoinService.getBalance(userId);
```

### Award Coins
```typescript
const transaction = await ggCoinService.awardCoins(
  userId,
  'tree_planting',
  1, // impact (number of trees)
  [{ condition: 'verified_with_photo', factor: 1.2 }] // multipliers
);
```

### Get Transaction History
```typescript
const history = await ggCoinService.getTransactionHistory(
  userId,
  50, // limit
  0   // offset
);
```

### Subscribe to Balance Updates
```typescript
const unsubscribe = ggCoinService.subscribeToBalance(
  userId,
  (newBalance) => {
    console.log('Balance updated:', newBalance);
  }
);
```

For complete API documentation, see [Technical Guide](../docs/TECHNICAL_GUIDE_NOVEMBER_19_2025.md).

## Migration from Green Coins

**Note**: The platform previously had two separate coin systems (GG Coins and Green Coins). These have been consolidated into a single unified GG Coin system.

### What Changed?
- **Single Currency**: Only GG Coins now (no more Green Coins)
- **Decimal Support**: GG Coins support fractional amounts
- **Unified Service**: One service handles all coin operations
- **Better Performance**: Caching and real-time updates

### What Stayed the Same?
- **Your Balance**: All previous balances were migrated
- **Transaction History**: Complete history preserved
- **Earning Methods**: Same actions earn coins
- **Spending Options**: Same uses for coins

### Migration Details
All Green Coin balances and transactions were automatically migrated to GG Coins with a 1:1 conversion rate. No action was required from users.
